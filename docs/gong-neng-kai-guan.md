# 功能开关

此页介绍的指令用于控制bot的功能

:::info
`<>`表示参数任取；`[]`表示参数可以省略。
:::


:::info
如果你发现bot只对一种功能毫无反应，请检查是否打开了该服务，参照下列指令

如果莫名其妙没反应了，大概率被**风控**了，只能等待tx解除风控
:::


| 指令示例      | 功能说明          |
| --------- | ------------- |
| &lt;lssv, 功能列表, 服务列表> | 查看本群服务        |
| 启用 *服务名*  | 启用某一个lssv中的服务 |
| 禁用 *服务名*  | 禁用某一个lssv中的服务 |
