# 自然语言定时提醒

<details>

<summary>开源地址</summary>

[https://github.com/madoka315/Aya-reminder](https://github.com/madoka315/Aya-reminder)

</details>

:::info
`<>`表示参数任取；`[]`表示参数可以省略。
:::


**该服务默认**<mark style="color:green;">**启用**</mark>

| 指令示例 | 功能说明 | 备注 |
| --- | --- | --- |
| 提醒我明天下午3点交周报 | 单次提醒 | 设置后需按 bot 提示确认 |
| @bot 半小时后开会 | 相对时间提醒 | 支持秒级相对时间（如「30秒后」） |
| @bot 每天18:30喂猫 | 循环提醒 | |
| @bot 每周五 20:00 公会战 | 每周循环提醒 | 时间与内容之间有无空格均可 |
| @bot 每周一三五 8:00 上班 | 多日循环提醒 | |
| @bot 每月1号九点发工资 | 每月循环提醒 | 支持中文数字写法 |
