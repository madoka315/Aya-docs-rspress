# B站动态推送

<details>

<summary>开源地址</summary>

[https://github.com/madoka315/Aya-bili-dynamic](https://github.com/madoka315/Aya-bili-dynamic)

</details>

:::info
`<>`表示参数任取；`[]`表示参数可以省略。
:::


**该服务默认**<mark style="color:green;">**启用**</mark>

| 指令示例 | 功能说明 | 备注 |
| --- | --- | --- |
| 关注动态 &lt;*UID*> [*关键词1*/*关键词2*] | 本群关注 | 有关键词则只推含关键词的动态 |
| 取关动态 &lt;*UID*> | 取消本群关注 | |
| 动态关注列表 | 查看本群关注 | |
| 更新动态 | 立即检查本群所有关注 | |
