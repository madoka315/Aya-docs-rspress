# 图片来源搜索

<details>

<summary>开源地址</summary>

[https://github.com/pcrbot/picfinder_take](https://github.com/pcrbot/picfinder_take)

</details>

:::warning
主要搜索源为SauceNAO, 如AI生成或私域图片是搜不到的. 可自行问网页版DeepSeek, 或去iqdb、ascii2d、Google lens等网站搜索
:::

**该服务默认**<mark style="color:green;">**启用**</mark>

| 指令示例        | 功能说明       | 备注               |
| ----------- | ---------- | ---------------- |
| @bot搜图 *图片* | 搜索单张图片     | 必须在同一条消息中包含at和图片 |
| 彩彩搜图        | 连续发送图片进行搜索 |                  |
