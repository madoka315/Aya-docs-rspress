# 问答

<details>

<summary>开源地址</summary>

[https://github.com/madoka315/Aya-qa](https://github.com/madoka315/Aya-qa)

</details>

:::info
`<>`表示参数任取；`[]`表示参数可以省略。
:::


**该服务默认**<mark style="color:green;">**启用**</mark>

| 指令示例 | 功能说明 | 备注 |
| --- | --- | --- |
| &lt;大家说,有人说> *问题* 回答 *内容* | 设置全群问答 | 仅群管理员及以上可设置；回答可带文字、图片或@ |
| 我说 *问题* 回答 *内容* | 设置个人问答 | 只有设置者本人触发时才会回复 |
| 我说 *关键词1\|关键词2* 回答 *内容* | 设置多关键词问答 | 任一关键词触发同一回答，关键词按字面匹配 |
| 我说 R*正则* 回答 *内容* | 设置正则问答 | 问题前加 R 且包含正则符号；普通 R 开头的问题不会误判 |
| 问答 | 查看自己设置的问答 | |
| 问答 *@某人* | 查看某人设置的问答 | |
| &lt;全部问答,所有问答> | 查看本群全部问答 | 分「全群问答」「个人专属问答」两区，长列表自动转为图片 |
| &lt;全部问答,所有问答> *关键词* | 搜索包含关键词的问答 | |
| 不要回答 *问题* | 删除一个问答 | 无需记住是否带 R，自动识别普通、正则和多关键词问答 |
| 更换回答 *问题* *内容* | 替换单条问答 | |
| 清空回答 *问题* | 清空该问题的全部回答 | 仅超级管理员 |
