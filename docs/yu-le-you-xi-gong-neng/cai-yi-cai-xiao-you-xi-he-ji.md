# 猜一猜小游戏合集

<details>

<summary>开源地址</summary>

猜头像：[https://github.com/GWYOG/GWYOG-Hoshino-plugins](https://github.com/GWYOG/GWYOG-Hoshino-plugins)

猜语音：[https://github.com/GWYOG/HoshinoBotVoiceGuessPlugin](https://github.com/GWYOG/HoshinoBotVoiceGuessPlugin)

金币系统：[https://github.com/madoka315/Aya-coinboard](https://github.com/madoka315/Aya-coinboard)

</details>

:::info
`<>`表示参数任取；`[]`表示参数可以省略。
:::


**该服务默认**<mark style="color:green;">**启用**</mark>**；可以分别开关各个功能**

| 指令示例         | 功能说明                         |
| ------------ | ---------------------------- |
| 猜头像          | 根据角色头像的一部分猜角色名               |
| 猜立绘          | 根据角色立绘的一部分猜角色名               |
| 猜语音          | 猜剧情语音                        |
| cygames      | 猜游戏启动时的“cygames”语音           |
| 猜ub          | 猜角色的ub语音                     |
| 金币排行榜          | 查看本群金币排行，全娱乐功能通用               |
