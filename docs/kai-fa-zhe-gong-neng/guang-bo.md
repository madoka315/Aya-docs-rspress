# 广播

| 指令                 | 作用                                                 |
| ------------------ | -------------------------------------------------- |
| `广播 <内容>` / `bc <内容>` | 向名单内所有群发送（每群间隔 20 秒，结束后回报成功/失败/不在群数量）              |
| `广播列表` / `广播群`      | 查看名单（群号 + 群名，bot 不在的会标注）                            |
| `广播添加 <群号...>`     | 添加，支持空格/中英文逗号/顿号分隔多个                               |
| `广播删除 <群号...>`     | 删除，同上                                              |
